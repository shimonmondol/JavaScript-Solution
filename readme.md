# STN-7 Problem Solving Assessment

This repository contains solutions to the 20 problem-solving tasks from the STN-7 assessment. All solutions are written in standard JavaScript and consolidated into a single solution file.

## General Instructions & Rules Followed

1. **Language:** JavaScript (ES6+ standard).
2. **File Organization:** All solutions are kept in a single executable file with clear section headers and comments.
3. **Function Signatures:** Exact variable names, function names, and parameter structures are strictly preserved.
4. **No Hardcoded Output:** Every implementation handles arbitrary valid inputs and boundary conditions dynamically.
5. **In-Place Mutations:** Problems requiring in-place changes (`moveZeroes`, `merge`, `reverseString`, `removeDuplicates`) modify the input array directly without returning new container arrays when required.
